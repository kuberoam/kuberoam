## 📖 About Roam

**Roam** is a premium, secure, and cross-platform mobile application designed for DevOps engineers, software developers, and system administrators. It enables you to manage, monitor, and troubleshoot your Kubernetes clusters securely on the go.

### ✨ Key Features

* **Rich Overview Dashboard**: Instant health checks with real-time resource utilization metrics, node status, and critical cluster-wide events.
* **Deep Node Inspection & Operations**: View hardware details, inspect running Pods, and perform node maintenance (Cordon/Uncordon, Drain, Delete) from your phone.
* **Advanced Workload Management**: Monitor Deployments, Pods, StatefulSets, and more. Scale workloads, trigger restarts, or view raw YAML definitions on the fly.
* **Live Log Viewer**: Terminal-style log viewer with real-time streaming, search, regex filtering, and severity highlighting.
* **Real-time Issue Tracking**: Automatically detects and groups cluster events into Critical, Warning, and Info severity levels.

### 🔒 Security-First Architecture

Your security is our top priority. 
* **Zero Middlemen**: Roam connects **directly** from your device to your Kubernetes API server. Your credentials and cluster data *never* pass through any third-party servers.
* **Hardware Encryption**: All cluster configurations and Kubeconfig files are stored locally using device-level hardware encryption (Keychain for iOS, Keystore for Android).
